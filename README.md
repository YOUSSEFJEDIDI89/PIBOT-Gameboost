## 📥 التثبيت (Termux)

```bash
pkg update -y && pkg install -y git
git clone https://github.com/YOUSSEFJEDIDI89/PIBOT-Gameboost
cd PIBOT-Gameboost
bash install.sh      # يبني نسخة C++ تلقائياً
pibot
```

### 🔨 البناء اليدوي (C++ / CMake)

```bash
pkg install -y clang cmake make libcurl
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
cp build/pibot $PREFIX/bin/
```

أو بدون CMake:

```bash
clang++ -std=c++17 -O2 src/*.cpp -o $PREFIX/bin/pibot
```

## 🔌 كيف تحصل على التأثير الكامل بدون روت؟ (دقيقتان)

أندرويد 11 وأحدث فيه **التصحيح اللاسلكي** الذي يعطي Termux صلاحيات `shell` الحقيقية:

1. فعّل **خيارات المطور** (اضغط 7 مرات على رقم الإصدار)
2. فعّل **التصحيح اللاسلكي**
3. افتح `pibot` ← الخيار **[7]** واتبع المعالج (إقران بالرمز ثم اتصال)
4. انتهى! كل الميزات العميقة أصبحت تعمل — بدون روت وبدون كمبيوتر

> بديل: تطبيق **Shizuku** — الأداة تدعمه تلقائياً عبر `rish`.

## 📈 ماذا تتوقع فعلياً؟

- إذا كانت شاشتك 90/120Hz والنظام يخفضها: رفع التردد يرفع سقف الـFPS فعلاً (مثلاً من 60 إلى 90/120).
- Game Mode Performance + قتل الخلفية + وضع الأداء الثابت = ثبات أعلى للفريمات وتقليل التقطيع (jank) والسخونة المتأخرة.
- **كن واقعياً**: لا توجد أداة في العالم تحول هاتفاً ضعيفاً إلى قوي. نحن نستخرج أقصى ما يستطيعه جهازك — بأوامر أندرويد الرسمية الحقيقية، ويمكنك التحقق بنفسك من قياس FPS المدمج.
